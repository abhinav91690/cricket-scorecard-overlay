Privacy Policy

Last updated 19 October 2026

This policy covers two things run by the Topguns Cricket Club: the cricket scorecard overlay at score.abhinav.dev, and the club's highlights uploader, which publishes match highlights to the club's own YouTube channel.

The scorecard overlay

The overlay shows live scores from CricClubs inside streaming apps. To understand how it is used, it records a small number of anonymous usage events on our own server:

  • the type of event (for example, the overlay opening for a match), the CricClubs club and match it was opened for, and the display theme and logo settings;
  • the streaming app or browser, its version, the operating system, the screen size, the browser's user-agent string and the page that linked to the overlay;
  • the size the overlay is drawn at, the time zone and language your browser reports, the app it is shown inside when the browser says so (for example a Facebook or Instagram in-app browser), and the name of the website that linked to it — the site's name only, never the address of the page;
  • the approximate country and city of the request, and the name of the network it came from (for example your internet provider), as supplied by our hosting provider;
  • if you use Link Live Stream, the YouTube video ID you submitted and whether it worked;
  • an approximate viewer count, from a salted hash of the network address and browser that changes every day. The network address itself is not stored, and the daily change means a visitor cannot be followed from one day to the next;
  • while an overlay is showing a live match, a short signal every five minutes so we can measure how long it stays on screen. It carries a random number created for that page load alone, which is never stored on your device.

The overlay sets no cookies and uses no third-party analytics or advertising. Nothing is recorded when your browser sends Do Not Track, or in test and replay modes. The data is used only to produce usage statistics for the people who run the overlay, and it is not sold or shared.

The highlights uploader

The highlights uploader is a tool the club's volunteers run on their own computer to publish highlight clips of the club's matches.

  • It requests a single Google permission, youtube.upload, used only to upload the club's highlight videos to the club's own YouTube channel.
  • The sign-in token Google issues is stored only on that volunteer's computer, in its system keychain. It is never sent anywhere except to Google.
  • It does not read, store or share any information about other YouTube users or Google accounts.

Players

Highlight captions name the club's own players and their figures from the match scorecard. Players from opposing teams are not named. Contact details that scoring systems hold about players are never displayed or stored by either tool.

Contact and changes

Questions or requests about this policy, including removing a highlight, can be raised on the project's public repository at github.com/abhinav91690/cricket-scorecard-overlay/issues. If this policy changes, the date at the top of the page will change with it.
