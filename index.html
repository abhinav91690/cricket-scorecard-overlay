Link a YouTube live stream

Attach your stream to the match on CricClubs so people can find it from the scorecard.

A youtube.com/watch or youtu.be link.

Briefly opens a small CricClubs window, so allow pop-ups for this site. CricClubs can take up to a minute to show the change.

All URL parameters
ParameterRequiredWhat it does
matchIdYesThe CricClubs match to follow.
clubIdNoCricClubs club ID. Defaults to 1089463 (LPCL).
themeNoOne of the themes above. Defaults to modern-light.
logoNoShows a sponsor logo in the top-right corner (1 or 2).
debugNoSample data instead of a live match: 1 first innings, 2 chase, 3 result, 4 toss, 5 no logos.
modeNoreplay cycles through a recorded match to test transitions.
nostatsNoOpts this browser out of anonymous usage statistics.

Open source on GitHub. Anonymous usage statistics help improve the overlay; add ?nostats=1 to opt out.
